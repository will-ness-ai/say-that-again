Your main checkout is on a detached HEAD at the old master tip (`f5dd80a`). A plain `git pull` will not work as is. Run these commands:

```sh
cd ~/projects/toolkit
git switch master
git pull
```

This is what the commands touch:

```
~/projects/toolkit/
├── prototypes/
│   └── lanes-board.html  (local edit, 2 lines)
├── CONTEXT.md            (untracked)
├── src/                  (modified by merge)
└── README.md             (modified by merge)
```

The merge changed `src/` and `README.md`. Your local edit in `prototypes/lanes-board.html` and the untracked `CONTEXT.md` are safe. They will be carried over without conflict.

You do not need to run `bun install` because the merge did not add any dependencies. There is no build step. When you next run `bun src/sync.ts` (or use `--watch`), it will use the new `lanes-board` code right away.

After that, a sync pass against a live map gives you the first real `lanes #<n>` tab. If you type `! cd ~/projects/toolkit && git switch master && git pull` in the prompt, the update runs right here and I can see the result.
