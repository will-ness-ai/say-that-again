# Demo script spec for route CLI

`glow` 2.1.1 is installed and renders inline with no pager. Frontier starts empty.

## Setup

Write `{"ticketSkills": {}}` to `demo-repo/.route/config.json` before you start.

Group `DEMO` will create `DEMO 2`, `DEMO 3` when names collide. The anchor is auto-made and stays invisible. Two rows show on screen.

## Recording path

Go left to right: docs site → docs-site → an-author → route (before state) → jump to grill-ui → back → tab 5 add → tab 6 config → back to tab 4, re-run (after state) → examples → axi.md → github.

When done, focus row 1, tab 1.

## Risk to confirm

If session `a1b2c3d4-…` is still open on `surface:199` when you run the script, two `claude` processes will write to one transcript. Close that tab first, or accept the collision.

The script will be `scripts/demo-workspace.sh`, executable, not committed unless you ask.
