# Confirmation flow for Open and Close transitions

```
Command: /pillar-list visibility:[public|private]

├─ State already matches?
│  └─ Yes → Report current state, exit
│
└─ No → Show ephemeral confirmation
   │
   ├─ Open (→ public)
   │  └─ Prompt: "This makes the full message history of #x readable 
   │     by ~N verified members. A later close does not undo that. 
   │     Continue?"
   │
   └─ Close (→ private)
      └─ Prompt: "~N verified members lose access to #x. 
         They get no notification. Continue?"
   
   Buttons: [Confirm] [Cancel]
   Expiry: 60 seconds (expiry = cancel)
   
   Batch form: One confirmation for all channels, 
               with channel list in prompt
```
