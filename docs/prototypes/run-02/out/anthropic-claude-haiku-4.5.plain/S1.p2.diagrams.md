# Confirmation flow for open and close operations

```
Command: /pillar visibility [public|private]

├─ State already matches?
│  └─ Yes → Report current state, exit
│
└─ No → Show ephemeral confirmation
   │
   ├─ Open (→ public)
   │  └─ "This makes the full message history of #x readable by ~N verified members.
   │     A later close does not undo that. Continue?"
   │     [Confirm] [Cancel] (expires 60s)
   │
   └─ Close (→ private)
      └─ "~N verified members lose access to #x.
         They get no notification. Continue?"
         [Confirm] [Cancel] (expires 60s)

Batch form (/pillar-list):
└─ One confirmation covers all channels
   └─ Prompt includes full channel list
```
