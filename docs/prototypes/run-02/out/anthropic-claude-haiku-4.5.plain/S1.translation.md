**Q5 — Confirmation: which directions need confirmation, and what should they say?**

Step back. The two directions each have a risk, both already known:

- **Open (→ public):** the channel gives `read_message_history` to all verified members. The full private history becomes readable right away. If you close it later, that does not take it back — people already read it while it was open. Ticket #109 asked if the open path should warn about this.
- **Close (→ private):** every verified member who does not have the composite role loses the channel right away. Auto-grant (#111) kept the people who posted. People who only read lose it with no alert. The ticket asks if the command should name that number.

What the code tells us: the bot keeps all members in the gateway cache. `/pillar-list` already counts role holders from that cache. So both counts are fast:

- Open: how many verified members gain access = verified count minus composite-role count.
- Close: how many lose access = the same number, for the same reason.

What this means:

- A confirmation step stops a slip of the hand. `visibility` is one choice on one command — `public` and `private` are one click apart.
- If the state already matches what you asked for, do not ask again. There is no change, so there is nothing to confirm. The command just reports the current state.
- The "all channels" form (Q2) should confirm once for the whole batch, not once per channel.

My recommendation: **confirm both directions with buttons that say Confirm or Cancel, and show the number in both.**

- Open: "This makes the full message history of #x readable by ~N verified members. A later close does not undo that. Continue?"
- Close: "~N verified members lose access to #x. They get no notification. Continue?"
- Skip confirmation if the state already matches — the command only reports, and fixes any drift it finds.
- One confirmation covers all channels in the batch form, with the channel list in the prompt.
- The buttons go away after 60 seconds. When they go away, treat it as cancel.
