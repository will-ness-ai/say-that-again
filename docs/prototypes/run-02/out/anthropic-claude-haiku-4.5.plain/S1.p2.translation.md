**Q5 — Confirmation: which directions confirm, and what do they say?**

Zoom out. The two directions have different risks, both known:

- **Open (→ public):** the channel lets all verified members read `read_message_history`. The full private history becomes readable right away. A later close does not take it back — people read it while it was open. Ticket #109 asked if the open path warns about this.
- **Close (→ private):** every verified member without the composite role loses the channel right away. Auto-grant (#111) kept the people who posted. Pure readers lose it with no message. The ticket asks if the command names that number.

Facts from the code: the bot holds all members in the gateway cache. `/pillar-list` already counts role holders from that cache. So both counts are fast:

- Open: how many verified members gain access = verified count minus composite-role count.
- Close: how many lose access = the same number, for the same reason.

Why this matters:

- A confirmation step stops a typo. `visibility` is one choice field on one command — `public` and `private` are one click apart.
- If the state already matches, do not ask. No transition means nothing to confirm. The command just reports the current state.
- The "all channels" form (Q2) must confirm once for the batch, not once per channel.

My recommendation: **confirm both directions with ephemeral Confirm/Cancel buttons, and show the number in both.**

```
Command: /pillar visibility [public|private]

├─ State already matches?
│  └─ Yes → Report current state, exit
│
└─ No → Show ephemeral confirmation
   │
   ├─ Open (→ public)
   │  └─ "This makes the full message history of #x readable by ~N verified members.
   │     A later close does not undo that. Continue?"
   │     [Confirm] [Cancel] (expires 60s)
   │
   └─ Close (→ private)
      └─ "~N verified members lose access to #x.
         They get no notification. Continue?"
         [Confirm] [Cancel] (expires 60s)

Batch form (/pillar-list):
└─ One confirmation covers all channels
   └─ Prompt includes full channel list
```
