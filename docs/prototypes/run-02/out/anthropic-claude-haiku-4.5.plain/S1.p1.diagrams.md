# Confirmation dialog flows for Open and Close operations

```
Open (→ public)
├─ Count: verified members - composite-role members = N
├─ Dialog (ephemeral, 60s timeout)
│  ├─ Message: "This makes the full message history of #x readable by ~N verified members. A later close does not undo that. Continue?"
│  └─ Buttons: [Confirm] [Cancel]
└─ On expiry: cancel

Close (→ private)
├─ Count: verified members - composite-role members = N
├─ Dialog (ephemeral, 60s timeout)
│  ├─ Message: "~N verified members lose access to #x. They get no notification. Continue?"
│  └─ Buttons: [Confirm] [Cancel]
└─ On expiry: cancel

Batch form (all channels)
├─ Single dialog (ephemeral, 60s timeout)
│  ├─ Message: [direction-specific] + channel list
│  └─ Buttons: [Confirm] [Cancel]
└─ On expiry: cancel

Idempotent case (state already matches)
└─ No dialog → command reports only, repairs drift if found
```
