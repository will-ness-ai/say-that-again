replaces: the confirmation logic and guard rails for both directions

```
/pillar-visibility channel:#x visibility:public
  ↓
state already public?
  ├─ yes → report "already public" (no confirm, no action)
  └─ no → show ephemeral confirm
         "This makes full message history readable by ~N verified members.
          A later close does not undo that. Continue?"
         [Confirm] [Cancel] (expires 60s)
         ├─ Confirm → transition to public
         └─ Cancel or expire → abort

/pillar-visibility channel:#x visibility:private
  ↓
state already private?
  ├─ yes → report "already private" (no confirm, no action)
  └─ no → show ephemeral confirm
         "~N verified members lose access to #x.
          They get no notification. Continue?"
         [Confirm] [Cancel] (expires 60s)
         ├─ Confirm → transition to private
         └─ Cancel or expire → abort

/pillar-visibility channel:all visibility:public|private
  ↓
collect all pillar channels
  ↓
state matches on all?
  ├─ yes → report "all already [public|private]"
  └─ no → show one ephemeral confirm for batch
         "[N channels] will change to [public|private]:
          #a, #b, #c, …
          [direction-specific warning]
          Continue?"
         [Confirm] [Cancel] (expires 60s)
         ├─ Confirm → transition all, report per-channel results
         └─ Cancel or expire → abort all
```
