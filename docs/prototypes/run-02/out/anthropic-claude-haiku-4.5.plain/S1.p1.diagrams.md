# supplements

```
Confirmation Logic

  Command issued
       │
       ├─→ Declared state matches current state?
       │        YES → Report only, no confirmation
       │        NO  → Continue
       │
       ├─→ Single channel?
       │        YES → Show direction-specific prompt
       │        NO  → Show batch prompt with channel list
       │
       ├─→ Display ephemeral Confirm/Cancel buttons
       │
       ├─→ User action or 60s timeout?
       │        Confirm → Execute transition
       │        Cancel  → Abort
       │        Timeout → Abort (cancel)
```
