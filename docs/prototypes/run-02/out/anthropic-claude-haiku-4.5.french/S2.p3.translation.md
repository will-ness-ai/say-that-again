Votre copie locale est bloquée sur un **HEAD détaché** à l'ancienne pointe de master (`f5dd80a`), donc un simple `git pull` ne fonctionnera pas. Lancez :

```sh
cd ~/projects/toolkit
git switch master
git pull
```

**État actuel et ce qui se passe :**

Avant la commande, vous êtes ici :
- HEAD (détaché) pointe sur `f5dd80a` (l'ancienne pointe de master)
- master en amont a avancé de 34 commits

Après `git switch master && git pull` :
- HEAD est sur master
- Vous pointez sur la pointe actuelle de master

**Ce qui bouge avec vous :**

Vos changements locaux restent :
- `prototypes/lanes-board.html` : 2 lignes modifiées, aucun changement en amont, donc pas de conflit
- `CONTEXT.md` : non suivi, reste en place

Les changements en amont fusionnent :
- `src/` : aucune modification locale
- `README.md` : aucune modification locale

**Après la fusion :**

- Pas besoin de `bun install` — la fusion n'a ajouté aucune dépendance
- Pas d'étape de build, donc le prochain `bun src/sync.ts` (ou `--watch`) utilise immédiatement le nouveau code
- Un passage de sync sur une carte en direct vous donne le premier vrai onglet `lanes #<n>`
