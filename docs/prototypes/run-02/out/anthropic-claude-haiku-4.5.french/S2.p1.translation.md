Votre checkout principal se trouve sur une **HEAD détachée** à l'ancienne pointe de master (`f5dd80a`), donc un simple `git pull` ne fonctionnera pas tel quel. Lancez :

```sh
cd ~/projects/toolkit
git switch master
git pull
```

Notes sur ce que cela touche :

- Vous avez une petite modification locale (2 lignes) dans `prototypes/lanes-board.html` et un `CONTEXT.md` non suivi. Les deux sont sûrs : la fusion a changé seulement `src/` et `README.md`, donc le changement de branche et la mise à jour les conservent sans conflit.
- Aucun `bun install` n'est nécessaire — la fusion n'a ajouté aucune dépendance. Il n'y a pas d'étape de build, donc la prochaine exécution de `bun src/sync.ts` (ou `--watch`) utilise immédiatement le nouveau code lanes-board.

Après cela, une passe de sync contre une carte en direct vous donne le premier vrai onglet `lanes #<n>`. Si vous tapez `! cd ~/projects/toolkit && git switch master && git pull` dans l'invite, la mise à jour s'exécute ici et je peux voir le résultat.

