Votre checkout principal est sur une **HEAD détachée** à l'ancienne pointe de master (`f5dd80a`), donc un simple `git pull` ne fonctionnera pas. Lancez :

```sh
cd ~/projects/toolkit
git switch master
git pull
```

Ce que cette commande touche :

- Vous avez une petite modification locale (2 lignes) dans `prototypes/lanes-board.html` et un fichier non suivi `CONTEXT.md`. Les deux sont sûrs : la fusion a changé seulement `src/` et `README.md`, donc le changement de branche et le pull les conservent sans conflit.
- Pas besoin de `bun install` — la fusion n'a ajouté aucune dépendance. Il n'y a pas d'étape de build, donc le prochain appel `bun src/sync.ts` (ou `--watch`) utilise le nouveau code lanes-board immédiatement.

Après cela, une passe de sync contre une vraie carte vous donne le premier vrai tab `lanes #<n>`. Si vous tapez `! cd ~/projects/toolkit && git switch master && git pull` dans le prompt, la mise à jour s'exécute ici et je peux voir le résultat.

```text
État actuel (HEAD détachée) :
  HEAD → f5dd80a (ancienne pointe de master)
  master → (34 commits en avant, inaccessible)

Après git switch master && git pull :
  HEAD → master → (dernier commit avec les nouvelles commandes)
  
Fichiers touchés par la fusion :
  ✓ src/          (changé en amont, sera mis à jour)
  ✓ README.md     (changé en amont, sera mis à jour)
  ✓ prototypes/lanes-board.html  (votre modification de 2 lignes, conservée sans risque)
  ✓ CONTEXT.md    (non suivi, inchangé)
```

Tapez `! cd ~/projects/toolkit && git switch master && git pull` pour mettre à jour maintenant ?
