# supplements

```
Cost of confirmation:

  Open:  verified_count - composite_role_count = N affected
  Close: verified_count - composite_role_count = N affected
         (same calculation, same data from gateway cache)

  ✓ Both counts already cheap (cache lookup)
  ✓ No confirmation if state already matches (idempotent)
  ✓ Batch form: one confirmation for all channels
```
