# Confirmation flow for Open and Close transitions

```
Command: /pillar-list visibility:public/private [channels]

├─ Check: declared state matches current state?
│  ├─ Yes → Report only (no confirmation needed)
│  └─ No → Proceed to confirmation
│
├─ Calculate affected members
│  ├─ Open (→public):  verified_count - composite_role_count = N
│  └─ Close (→private): verified_count - composite_role_count = N
│
├─ Show confirmation (ephemeral, 60s expiry)
│  ├─ Open:  "This makes the full message history of #x readable by ~N verified members.
│  │         A later close does not undo that. Continue?"
│  │         [Confirm] [Cancel]
│  │
│  └─ Close: "~N verified members lose access to #x.
│            They get no notification. Continue?"
│            [Confirm] [Cancel]
│
├─ Batch form: one confirmation for all channels
│  └─ Prompt includes full channel list
│
└─ User action
   ├─ Confirm → Execute transition
   ├─ Cancel → Abort
   └─ Timeout (60s) → Cancel
```
