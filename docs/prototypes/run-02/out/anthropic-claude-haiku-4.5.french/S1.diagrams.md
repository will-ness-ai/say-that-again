replaces: the confirmation logic and its two cases

```
/pillar-visibility channel:#x visibility:public
  ↓
state already public?
  ├─ yes → report "already public" (no confirm)
  └─ no → show confirm prompt
         "This makes the full message history of #x readable by ~N verified members.
          A later close does not undo that. Continue?"
         [Confirm] [Cancel] (expires 60s)

/pillar-visibility channel:#x visibility:private
  ↓
state already private?
  ├─ yes → report "already private" (no confirm)
  └─ no → show confirm prompt
         "~N verified members lose access to #x.
          They get no notification. Continue?"
         [Confirm] [Cancel] (expires 60s)

/pillar-visibility channel:all visibility:public|private
  ↓
state already matches on all?
  ├─ yes → report "all already [public|private]" (no confirm)
  └─ no → show one confirm prompt for the batch
         "[channel list]
          This affects ~N verified members across all channels.
          [direction-specific warning]
          Continue?"
         [Confirm] [Cancel] (expires 60s)
```
