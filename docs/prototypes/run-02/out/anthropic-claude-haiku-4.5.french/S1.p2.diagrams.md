replaces: the confirmation logic and its conditions

```text
on(/pillar-visibility)
  if declared state matches current state
    report convergence
    return
  
  if batch form (channel: all)
    show one confirmation
      list all channels
      show total member count
    on confirm
      apply to every channel
      report results
  else
    show per-channel confirmation
      show member count for this channel
    on confirm
      apply to this channel
      report result
  
  on expiry (60s) or cancel
    abort, report nothing
```

OPEN (→ public)
