replaces: the confirmation logic and its two cases

```text
on(/pillar-visibility)
  if declared state matches current state
    report convergence
    return
  
  if direction is open (→ public)
    count = verified members − composite members
    prompt: "Makes history readable by ~{count}. A later close does not undo. Continue?"
    on(Confirm) → grant read_message_history, report
    on(Cancel or 60s) → report cancellation
  
  if direction is close (→ private)
    count = verified members − composite members
    prompt: "~{count} members lose access. No notification sent. Continue?"
    on(Confirm) → revoke read_message_history, report
    on(Cancel or 60s) → report cancellation
  
  if batch form (channel: all)
    count total transitions across all channels
    one prompt covers all
    on(Confirm) → apply all, report per-channel results
```

supplements: why both directions need confirmation

| Direction | Danger | Confirmation shows |
|-----------|--------|-------------------|
| Open → public | History becomes readable; close does not retract it | Count of members gaining access |
| Close → private | Members lose access silently | Count of members losing access |
