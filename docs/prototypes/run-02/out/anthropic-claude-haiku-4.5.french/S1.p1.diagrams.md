# replaces-prose

```
┌─────────────────────────────────────────────────────────────┐
│ CONFIRMATION FLOW                                           │
└─────────────────────────────────────────────────────────────┘

OPEN (→ public)
├─ Condition: declared state differs from current
├─ Prompt: "This makes the full message history of #x 
│           readable by ~N verified members. 
│           A later close does not undo that. Continue?"
├─ Count: verified members − composite-role members
└─ Buttons: [Confirm] [Cancel] (expire 60s)

CLOSE (→ private)
├─ Condition: declared state differs from current
├─ Prompt: "~N verified members lose access to #x. 
│           They get no notification. Continue?"
├─ Count: verified members − composite-role members
└─ Buttons: [Confirm] [Cancel] (expire 60s)

IDEMPOTENT (state already matches)
├─ No confirmation
├─ Command reports only
└─ Repairs drift if found

BATCH (all channels)
├─ One confirmation for entire batch
├─ Prompt includes channel list
└─ Buttons: [Confirm] [Cancel] (expire 60s)
```
