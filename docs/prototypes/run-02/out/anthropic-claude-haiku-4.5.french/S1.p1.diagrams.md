# Confirmation flow for Open and Close transitions

```
Command: /pillar-list visibility:public (or private)

├─ Check: does declared state match current state?
│  ├─ YES → Report current state, repair any drift, exit
│  └─ NO → proceed to confirmation
│
├─ Calculate affected members
│  ├─ Open (→public):  verified_count - composite_role_count = N gain access
│  └─ Close (→private): verified_count - composite_role_count = N lose access
│
├─ Show ephemeral confirmation prompt with count
│  ├─ Open:  "This makes the full message history of #x readable by ~N verified members.
│  │         A later close does not undo that. Continue?"
│  │         [Confirm] [Cancel] (expires 60s)
│  │
│  └─ Close: "~N verified members lose access to #x.
│            They get no notification. Continue?"
│            [Confirm] [Cancel] (expires 60s)
│
└─ On Confirm → execute transition
   On Cancel or Expiry → abort, no change
```

**Batch form (all channels):** one confirmation covers all channels, with channel list in prompt.
