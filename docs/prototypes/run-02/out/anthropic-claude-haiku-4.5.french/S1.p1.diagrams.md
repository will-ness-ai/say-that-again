supplements: the confirmation logic and what each path shows

```
/pillar-visibility channel:#x visibility:public

  ↓ check current state

  state matches?
  ├─ yes → report "already public" + repair any drift
  └─ no  → show confirmation
           ├─ Open (→public):  "~N members gain access. History stays readable. Continue?"
           ├─ Close (→private): "~N members lose access. No notification. Continue?"
           └─ [Confirm] [Cancel] (expires 60s)
              ├─ Confirm → apply + report
              └─ Cancel or expire → report "cancelled"

/pillar-visibility channel:all visibility:public

  ↓ collect all pillar channels

  any state mismatch?
  ├─ no  → report "all already public"
  └─ yes → show one confirmation for the batch
           "Channels: #a, #b, #c
            ~N members gain access across all. Continue?"
           └─ [Confirm] [Cancel] (expires 60s)
```
