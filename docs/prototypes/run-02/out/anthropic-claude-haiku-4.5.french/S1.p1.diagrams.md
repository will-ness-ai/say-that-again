replaces: the confirmation logic and its two cases

```text
on(/pillar-visibility channel:#x visibility:public|private)
  if declared state matches current state
    report convergence
    return
  
  if visibility:public
    count = verified members minus composite members
    prompt: "This makes full history readable by ~{count} verified members.
             A later close does not undo that. Continue?"
    on(Confirm)
      grant read_message_history to verified role
      report success
    on(Cancel or 60s timeout)
      report cancelled
  
  if visibility:private
    count = verified members minus composite members
    prompt: "~{count} verified members lose access to #x.
             They get no notification. Continue?"
    on(Confirm)
      revoke read_message_history from verified role
      report success
    on(Cancel or 60s timeout)
      report cancelled

on(/pillar-visibility channel:all visibility:public|private)
  channels = all pillar channels
  count_open = sum of (verified - composite) per channel
  count_close = sum of (verified - composite) per channel
  
  if visibility:public
    prompt: "Open {N} channels, making history readable by ~{count_open}
             verified members total. Continue?"
  if visibility:private
    prompt: "Close {N} channels. ~{count_close} verified members lose access.
             Continue?"
  
  on(Confirm)
    for each channel
      apply visibility change
      report per-channel result
  on(Cancel or 60s timeout)
    report cancelled
```
