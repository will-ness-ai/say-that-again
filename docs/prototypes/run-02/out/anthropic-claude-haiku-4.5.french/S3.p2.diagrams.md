supplements: the pre-flight and collision rule

Pre-flight writes to `demo-repo/.route/config.json`:
```json
{"ticketSkills": {}}
```

Group `DEMO` creates anchor (invisible) and two visible rows. On duplicate names: `DEMO`, `DEMO 2`, `DEMO 3`, etc.

supplements: the session risk

If session `a1b2c3d4-…` is still open in `surface:199` when you run the script, two `claude` processes will write one transcript. Close that tab first, or accept the collision.
