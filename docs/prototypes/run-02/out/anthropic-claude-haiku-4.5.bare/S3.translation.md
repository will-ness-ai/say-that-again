# Setup for glow 2.1.1 Demo

`glow` 2.1.1 is already installed and ready to use. It shows markdown inline without a pager — the same way tab 7 works now. Nothing else is set up yet.

## What you need to do first

Write this to `demo-repo/.route/config.json`:

```json
{"ticketSkills": {}}
```

## What you will see

You get a group called `DEMO` with two visible rows. The system creates a hidden anchor row automatically.

### Row 1 — route-cli tool (one panel, working folder: demo-repo)

Nine tabs open. Each terminal clears the screen before it runs, so you won't see setup commands.

## How to navigate

1. Start at docs site
2. Go to docs-site
3. Go to an-author
4. Run `route` (tab 4, before state)
5. **Jump to grill-ui**
6. Come back
7. Send tab 5 (add the skill)
8. Send tab 6 (check config)
9. **Go back to tab 4 and run it again** (after state)
10. Go to examples
11. Go to axi.md
12. Go to github

When done, focus returns to row 1, tab 1.

## One thing to watch

You chose `--resume` instead of `--fork-session`. If the session `a1b2c3d4-…` is still open in another tab when you run this script, two `claude` processes will write to the same transcript. Close that tab first, or accept the risk.

The script lives in `scripts/demo-workspace.sh`. It is executable and not saved to git unless you ask.
