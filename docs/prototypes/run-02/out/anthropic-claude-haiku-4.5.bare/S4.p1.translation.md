# My Call: Keep, Don't Invest

**Why keep wins.** Kill pins a server-wide collapse on the most stable part—the worst wrong answer if we're wrong. Improve throws effort at a supply problem that no format fix solves. Keep costs nothing and keeps the door open if the server comes back.

---

## What makes "keep, don't invest" actionable?

The problem: kill and keep are "easy to write, hard to act on." A tiny conclusion can't include a full plan—and this map doesn't cover how to act anyway. So what's the smallest thing that turns the verdict into a real decision?

Three pieces:

**1. Say what we won't do**
- No new tools
- No format redesign  
- No recurring metrics pipeline
- No kill

**2. Name the conditions that reopen this**
When do we ask the question again?
- If updates stop for a full quarter (the surface died on its own)
- If the server comes back strong (then "improve" might be worth the cost)

**3. Point to one cheap next step**
The data can't see direct messages, introductions, or offline use. But it shows who got the most visible value. The conclusion notes: ask them directly. That's the cheapest way to catch what we missed. (Actually running that survey is a separate effort, outside this map.)
