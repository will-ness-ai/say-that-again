# Confirmation flow for Open and Close directions

```
Command: /pillar-list visibility:[public|private]

├─ State already matches?
│  └─ Yes → Report current state, exit
│
└─ No → Show ephemeral confirmation
   │
   ├─ Open (→ public)
   │  └─ "This makes the full message history of #x readable by ~N verified members.
   │     A later close does not undo that. Continue?"
   │
   └─ Close (→ private)
      └─ "~N verified members lose access to #x.
         They get no notification. Continue?"
   │
   ├─ [Confirm] → Execute transition
   ├─ [Cancel]  → Exit
   └─ (60s timeout) → Cancel
```

# Member count calculation (both directions)

```
Verified members affected = verified_count − composite_role_count

Open:  members who GAIN access
Close: members who LOSE access
```

# Batch form confirmation

```
Single confirmation prompt covers all channels:

"~N verified members lose access to: #channel-a, #channel-b, #channel-c
They get no notification. Continue?"

[Confirm]  [Cancel]
```
