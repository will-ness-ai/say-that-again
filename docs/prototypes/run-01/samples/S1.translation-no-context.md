**Q5 — Confirmation: which directions need a confirmation, and what does it say?**

Step back. The two directions carry different dangers. Both were settled in earlier tickets:

- **Open (→ public):** the channel gives `read_message_history` to all verified members. The whole private history becomes readable immediately. Closing it later does not take that back — people read it while it was open. Ticket #109 left the question "does the open path warn about this?" to this ticket.
- **Close (→ private):** every verified member who does not have the composite role loses the channel immediately. Auto-grant (#111) protects the people who posted. People who only read lose access with no signal. This ticket asks whether the command tells you how many.

Facts from the code: the bot keeps all members in the gateway cache. `/pillar-list` already counts role holders from that cache. So both counts are cheap to get:

- Open: the number of verified members who gain access = verified count minus composite-role count.
- Close: the number who lose access = the same number, for the same reason.

What this means:

- A confirmation step guards against a slip in the arguments. `visibility` is one choice field on one command — `public` and `private` are one click apart.
- The no-change case must not nag. If the channel is already in the state you declared, nothing changes, so there is nothing to confirm. The command just converges and reports.
- The "all channels" form (Q2) must confirm one time for the whole batch, not one time per channel.

My recommendation: **confirm both directions with ephemeral Confirm/Cancel buttons, and show the number in both.**

```
N = verified_members - composite_role_holders     # both counts read from the gateway cache

on command(channels, visibility):
    changing = [c in channels where c.state != visibility]

    if changing is empty:                         # declared state already matches
        report state
        repair drift if found
        return                                    # nothing to confirm

    if visibility == public:
        text = "This makes the full message history of #x readable by
                ~N verified members. A later close does not undo that. Continue?"
    else:
        text = "~N verified members lose access to #x.
                They get no notification. Continue?"

    show ephemeral prompt(text, list of `changing`) + [Confirm] [Cancel]
                                                  # one prompt for the whole batch

    wait 60s:
        Confirm -> apply
        Cancel  -> stop
        expiry  -> stop                           # expiry means cancel
```
