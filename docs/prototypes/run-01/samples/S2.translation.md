Your main checkout is not on a branch. It sits on a **detached HEAD**, parked at the old tip of `master` (`f5dd80a`). So a plain `git pull` will not work as things stand. Run this:

```sh
cd ~/projects/toolkit
git switch master
git pull
```

What this touches:

- You have a small local edit (2 lines) in `prototypes/lanes-board.html`, and an untracked `CONTEXT.md`. Both are safe. The merge changed only `src/` and `README.md`, so the switch and the pull carry both files over with no conflict.
- You do not need `bun install` — the merge added no dependencies. There is no build step, so your next `bun src/sync.ts` run (or `--watch`) uses the new lanes-board code right away.

After that, run a sync pass against a live map. It gives you your first real `lanes #<n>` tab. If you type `! cd ~/projects/toolkit && git switch master && git pull` at the prompt, the update runs right here, and I can see the result.
