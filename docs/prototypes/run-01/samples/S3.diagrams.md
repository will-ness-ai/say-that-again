```text

anchor pane auto-made, invisible  ·  2 visible rows
every terminal runs `clear` before its display command, so no cd/setup shows
│

│   ├─ 2  browser   docs.example.dev /route
│   ├─ 3  browser   an-author SKILL.md
│   ├─ 4  terminal  route                                     pre-run
│   │               └ "No ticket skills are registered"
│   ├─ 5  terminal  route --help                              pre-run
│   │               then route ticket-skill add grill-design --when "…"
│   │               └ typed, not sent
│   ├─ 6  terminal  cat .route/config.json                    typed, not sent
│   ├─ 7  terminal  cat examples.md | glow                    pre-run
│   ├─ 8  browser   axi.md
```
